
# Product Backlog – Hospital Appointment Booking Application

## Epic 1: Appointment Booking

### US01 – View Doctors
As a patient, I want to view the list of available doctors, so that I can choose a doctor for my medical needs.

### US02 – View Available Appointment Slots
As a patient, I want to view available appointment slots for a selected doctor, so that I can choose a convenient time.

### US03 – Book an Appointment
As a patient, I want to book an available appointment slot, so that I can consult a doctor.

## Epic 2: Rescheduling and Cancellation

### US04 – View Existing Appointments
As a patient, I want to view my upcoming appointments, so that I can manage my bookings.

### US05 – Reschedule an Appointment
As a patient, I want to select a new available appointment slot, so that I can change my existing appointment time.

### US06 – Cancel an Appointment
As a patient, I want to cancel an existing appointment, so that I can release the slot when I cannot attend.

## Epic 3: Reminders

### US07 – Receive Appointment Reminder
As a patient, I want to receive an appointment reminder before my scheduled visit, so that I do not forget my appointment.

### US08 – View Reminder Details
As a patient, I want to view my appointment reminder details, so that I can confirm the appointment date, time, and doctor.

### US09 – Manage Reminder Preferences
As a patient, I want to manage my reminder preferences, so that I can receive notifications through my preferred supported channel.

## Epic 4: Doctor Schedule Management

### US10 – View Doctor Schedule
As a doctor, I want to view my daily appointment schedule, so that I can prepare for patient consultations.

### US11 – Update Doctor Availability
As a doctor, I want to update my available consultation hours, so that patients can book appointments during my working hours.

### US12 – Block Unavailable Time Slots
As a doctor, I want to block unavailable time slots, so that patients cannot book appointments during my leave or other commitments.
