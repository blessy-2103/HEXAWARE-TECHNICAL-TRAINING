
# Product Backlog – Online Grocery Delivery Application

## Epic 1: Browse and Search

### US01 – View Grocery Categories
As a customer, I want to view grocery categories, so that I can find products easily.

### US02 – Search Grocery Products
As a customer, I want to search groceries by name, so that I can find a specific product.

### US03 – View Product Details
As a customer, I want to view product details and prices, so that I can make informed purchase decisions.

### US04 – Filter Products
As a customer, I want to filter products by category, so that I can find relevant groceries quickly.

## Epic 2: Cart and Checkout

### US05 – Add Products to Cart
As a customer, I want to add groceries to my cart, so that I can purchase multiple items together.

### US06 – Update Cart Quantity
As a customer, I want to update product quantities in my cart, so that I can adjust my order.

### US07 – Select Delivery Address
As a customer, I want to select a delivery address, so that groceries reach my preferred location.

### US08 – Online Payment
As a customer, I want to pay for my groceries online, so that I can complete my purchase conveniently.

## Epic 3: Delivery and Order Tracking

### US09 – Select Delivery Slot
As a customer, I want to select a delivery slot, so that I can receive groceries at a convenient time.

### US10 – Order Confirmation
As a customer, I want to view my order confirmation, so that I know my order has been placed successfully.

### US11 – Track Order
As a customer, I want to track my order status, so that I know when my groceries will arrive.

### US12 – Delivery Notifications
As a customer, I want to receive delivery notifications, so that I can stay informed about my order.

## Backlog Summary

- Total Epics: 3
- Total User Stories: 12
- All stories follow the As a / I want / so that format.
