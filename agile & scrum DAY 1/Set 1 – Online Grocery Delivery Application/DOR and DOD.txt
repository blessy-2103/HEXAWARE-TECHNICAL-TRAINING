DEFINITION OF READY
A story may enter a sprint only if:
- It is written in the As a / I want / so that format and passes the INVEST checklist.
- Acceptance criteria are written in Given / When / Then, including at least one negative case.
- It has been estimated by the team using Planning Poker, and anything above 8 points has been split.
- Dependencies (APIs, slot data, payment gateway account) are identified and available or scheduled.
- UI mockups or wireframes exist for user-facing stories.
- The Product Owner has prioritised it and the team understands it well enough to start.

DEFINITION OF DONE
A story is done only if:
- All acceptance criteria are met and demonstrated to the Product Owner.
- Code is peer-reviewed and merged to the main branch through the CI pipeline.
- Unit tests are written and passing (for example 80 percent coverage on new code), and integration tests pass.
- No open critical or high-severity defects remain on the story.
- It works on the supported browsers and on Android and iOS test devices.
- Security basics are checked (input validation, no card data stored by the app).
- Documentation is updated (API docs and release notes), and the feature is deployed to the staging environment.
- The Jira ticket is moved to Done with test evidence attached.
